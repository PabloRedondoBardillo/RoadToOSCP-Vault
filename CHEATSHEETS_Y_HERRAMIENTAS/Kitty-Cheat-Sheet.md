
Renombrar el espacio de trabajo
```bash 
ctrl + alt + shift + t
```

Crear una nueva ventana
```bash 
ctrl + shift + enter
```

Cambiar el modo de distribucion de las ventanas
```bash 
ctrl + shift + l
```

Eliminar la ventana
```bash 
ctrl + shift + w
```

Cambiar ventana
```bash 
ctrl + arriba/abajo/izquierda/derecha (flecha)
```

Mover ventana hacia delante
```bash 
ctrl + shift + f
```

Mover ventana hacia detras
```bash 
ctrl + shift + b
```

Crear nuevo espacio de trabajo
```bash 
ctrl + shift + t
```

Cambiar espacio de trabajo
```bash 
ctrl + shift + izquierda/derecha (flecha)
```

Entrar en modo resize
```bash 
ctrl + shift + r
```

Hacer un zoom a la venta actual
```bash 
ctrl + shift + z
```
