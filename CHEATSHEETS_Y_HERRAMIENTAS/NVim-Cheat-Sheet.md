
Entrar en modo insertar
```bash 
i
```

Entrar en modo visual
```bash 
v
```

Volver al modo normal
```bash 
esc
```

Ir a inicio de la linea (modo normal)
```bash 
0
```

Ir a fin de la linea (modo normal)
```bash 
$
```

Moverte entre palabras (modo normal)
```bash 
[numero de palabras (1)] + w
```

Borrar lineas (modo normal)
```bash 
[numero de lineas (1)] + dd
```

Borrar palabras (modo normal)
```bash 
[numero de palabras (1)] + d + w
```

Deshacer
```bash 
alt + u
```

Copiar (modo visual)
```bash 
y
```

Modo busqueda (modo normal)
```bash 
/texto_a_buscar
```
