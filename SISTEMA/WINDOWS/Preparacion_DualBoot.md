Desactivar el Inicio Rapido:
```bash
Panel de control > Opciones de energia > Elegir el comportamiento del boton inicio/apagado > Cambiar la configuracion actualmente no disponible > Desmarcar Activar Inicio Rapido
```

Suspender BitLocker:
**IMPORTANTE Crear copia de seguridad de la clave** 
```bash
Panel de control > Sistema y seguridad > Cifrado de unidad BitLocker > Copia de seguridad de la clave de recuperacion
```

```bash
Panel de control > Sistema y seguridad > Cifrado de unidad BitLocker > Suspender proteccion
```
