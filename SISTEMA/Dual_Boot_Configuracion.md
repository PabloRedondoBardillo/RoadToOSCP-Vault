Realizar todos los cambios en Windows sugeridos en [[Reduccion_Disco]] y [[Preparacion_DualBoot]].

### Bios
* Desactivar Secure Boot
* Desactivar Fast Boot
* Poner el USB con Arch el primero en Boot Priority
* Configuracion de almacenamiento:
Asegurarse que esta en AHCI. Si esta en RAID hay que forzar el modo seguro de Windows para que instale los drivers AHCI.

Guardar, salir y proceder con la instalacion de Arch [[Configuracion]]
